# Параметрическая табличка для растений

Файлы:

- `plate_base.stl` — основа 180 x 90 x 4 мм с задним глухим держателем под
  композитную арматуру 8 мм и пазом под надпись.
- `plate_text.stl` — отдельная цветная вставка с надписью `яблоня`.
- `plant_sign_generator.py` — генератор для произвольной надписи.

## Импорт в Bambu Studio

1. Импортируйте `plate_base.stl` и `plate_text.stl` вместе.
2. Если Bambu Studio спросит, считать ли файлы одним объектом с несколькими
   частями, выберите вариант assembly / multi-part object.
3. Назначьте `plate_base.stl` основной филамент, а `plate_text.stl` — второй
   цвет через AMS/второе сопло.
4. Модель уже сгенерирована лицевой стороной вниз: печать начинается с плоской
   таблички и цветного текста, а задний цилиндр печатается выше.
5. Внутри заднего глухого канала можно включить поддержки; при необходимости
   канал рассчитан на последующее рассверливание.

## Создание другой надписи

Из корня репозитория:

```bash
python3 outputs/plant_sign_generator.py --text "груша" --outdir outputs
```

Если вы уже находитесь внутри папки `outputs`:

```bash
python3 plant_sign_generator.py --text "груша" --outdir .
```

Если в обычном `python3` нет `numpy` или `Pillow`, скрипт автоматически
перезапустится через bundled Codex Python, когда он доступен на этой машине.

Полезные параметры:

```bash
--resolution 0.3              # более гладкий текст, но STL будет крупнее
--rod-clearance 0.8           # увеличить отверстие под арматуру
--holder-length 70            # сделать держатель длиннее
--text-margin-x 10            # дать тексту больше ширины
--text-depth 0.8              # глубина вплавления текста
--orientation front-up        # экспорт в старой ориентации, текстом вверх
```

По умолчанию канал под стойку получается 8.6 мм: арматура 8.0 мм плюс 0.6 мм
зазора. По умолчанию используется `--orientation face-down`, а текст делается
заподлицо с лицевой плоскостью.
